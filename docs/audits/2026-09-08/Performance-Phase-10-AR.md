# المرحلة العاشرة: تقليل تحميل قائمة الطلبات

التاريخ: 2026-09-11. الحالة: منفذة محليًا ومختبرة؛ لم تُنشر.

## التغيير

قائمة طلبات العميل تستخدم `OrderWithOutItemsResource` عندما لا يطلب العميل نوعًا يعرض العناصر. قبل التعديل كانت القائمة تحمل دائمًا علاقة `items` وعلاقات المنتجات والتصنيفات وتحديثات الكمية، حتى في الاستجابة المختصرة. أصبح تحميل هذه العلاقات مشروطًا بأن يكون النوع واحدًا من `clothes` أو `fastorder` أو `services` أو `sales`، وهي الأنواع التي تستخدم `OrderResource` وتعرض العناصر.

لم تتغير المسارات أو الحقول أو شروط الملكية والحالات أو طريقة الترقيم. عند طلب نوع يعرض العناصر يبقى eager loading كما كان. عند القائمة المختصرة تقل البيانات المحملة داخليًا فقط؛ لا يُفترض تغيير JSON الناتج.
