# تقدم إصلاحات Clean Station

آخر تحديث: 2026-09-11. هذه حالة التنفيذ المحلي، وليست إثباتًا لنشر جميع الإصلاحات أو إغلاق جميع بنود التدقيق الـ22.

**توجيه صاحب المشروع في هذه الجولة:** الحفاظ على تطبيق الزبائن، وترك الدفع والشحن كما هما. لم تتغير مسارات API أو حقول الاستجابات أو منطق الدفع والمحفظة والدخول، ولم تُنفذ ترحيلات أو عمليات على قاعدة العملاء. أفاد صاحب المشروع بأن الدفعات الحالية رُفعت إلى السيرفر وأن الأمور تعمل، دون أن أملك قياسات الخادم أو سجل نشر مستقل.

## آخر دفعة

[المرحلة التاسعة: حماية الاستجابات والبيانات وفحوص الجودة وواجهة الهاتف](Safe-Continuation-Phase-9-AR.md) والمرحلة العاشرة: تقليل تحميل قائمة الطلبات (Performance-Phase-10-AR.md):

- بقاء استجابة العملية الأصلية إذا تعطل سجل استخدام API، حتى لا يرى العميل فشلًا لعملية نجحت ويكررها.
- تنبيهات الاستثناءات تقتصر على بيانات تشخيصية محدودة؛ حذف جسم الطلب وURL الفعلي وبيانات المستخدم ونص الاستثناء وSQL من هذه التنبيهات، وتنقيح أخطاء إرسال Telegram.
- تحويل اختبارات المنتجات التي كانت تعتمد على قاعدة مجهزة إلى بيانات مصطنعة معزولة، وفحص اللغات والحقول والحالات غير النشطة والمحذوفة.
- تحديث حزم بناء الواجهة المتأثرة ضمن نطاقات الإصدارات الحالية؛ نتيجة npm audit الآن صفر تنبيهات.
- تقديم النص وروابط التحميل في بداية الموقع على الهاتف، وإظهار المحتوى عند تعطل الحركة ودعم تقليل الحركة.
- إضافة ملف CI لاختبارات التدقيق والبناء وتدقيق الاعتماديات، وإضافة packages/core إلى نطاق التغطية. لم يُشغّل CI على GitHub بعد.

**التحقق المحلي:** 69 اختبارًا و499 تحققًا ناجحًا على PHP 8.4.16، مع تفعيل الفشل عند الاختبارات الخطرة أو تحذيرات PHPUnit. بناء Vite ناجح في مجلد اختبار منفصل. عُرض قالب البداية ببيانات مصطنعة بالعربية والإنجليزية وتحقق العنوان وروابط التحميل. تعذرت المعاينة البصرية بسبب خطأ تشغيل المتصفح في البيئة؛ لا يُعد فحص القالب بديلًا عنها.

| البند | الحالة الحالية | ما بقي وحدود الإغلاق |
| --- | --- | --- |
| A02 — الوسائط والصلاحيات | حماية مسارات المعرض منفذة محليًا | تأكيد صلاحيات الموظفين الفعلية ومراجعة بقية الإدارة. |
| A03 — ملكية الطلب | حماية التفاصيل والحالة ومساري الدفع السريع منفذة سابقًا | مراجعة بقية أدوار الفني والسائق والشركات تحتاج سيناريوهاتهم وبيانات تجريبية. |
| A04 — الدفع | إصلاحات المراحل 2–4 موثقة سابقًا؛ خارج تعديلات هذه الجولة بتوجيه المستخدم | المسارات القديمة وتزامن الفواتير والمصالحة لم تُغلق، ولا يُغيرها هذا العمل. |
| A05 — الأسرار والسجلات | تنقية سجل الطلب وتنبيهات الاستثناءات منفذة | مفاتيح التكامل المثبتة وتدويرها والسجلات السابقة وبقية قنوات السجل تحتاج معالجة مستقلة مع إعدادات التشغيل. لا ادعاء بخلو المستودع من الأسرار. |
| A06 — الدخول والتعطيل | حماية الحساب المعطل منفذة سابقًا | آلية الدخول والرمز الثابت وحدود المحاولات لم تتغير حفاظًا على التوافق والاستثناء السابق. |
| A07 — الاعتماديات | حزم npm المعنية محدثة وفحصها نظيف | تنبيهات PHP في guzzlehttp/guzzle وlaravel/framework وleague/commonmark وmaatwebsite/excel، وحزمة toastr متروكة. ترقية الخادم تحتاج دورة توافق مستقلة. |
| A08 — رفع الملفات | حماية رفع المعرض منفذة في المرحلة 6 | مراجعة بقية مسارات الرفع وتنزيل الروابط؛ أخطاء الدفع خارج هذه الجولة. |
| P01 — الصور | المرحلة 7 مع أبعاد وأولوية وتأجيل صور | تحويل الصور القديمة وقياس LCP/CLS على الإنتاج لم ينجزا. |
| P02 — الكاش والمكتبات | حماية ظهور المحتوى عند تعطل مكتبة الحركة | ما زال نقل/تقليل مكتبات CDN وسياسة الكاش يحتاجان قياسًا ومراجعة الخادم. |
| P03 — السجلات والطوابير | قفل الجدولة سابقًا وحماية استجابة العميل الآن | زمن الانتظار وfailed_jobs ومدير العمال وتنظيف الدفعات تحتاج بيانات تشغيل. |
| P04 — الاستعلامات والكاش | تقليل تحميل عناصر قائمة الطلبات منفذ، وأفاد صاحب المشروع بأن النشر يعمل | يلزم قياس الاستعلامات وزمن p95 على خادم الإنتاج واختبار عقود شركات ومدن مختلفة. |
| S01 — عناوين المقالات | إصلاحات عنوان/وصف وتواريخ وH1 في الدفعات السابقة | مراجعة المحتوى الفعلي لكل المقالات على الإنتاج. |
| S02 — robots والصور | السماح بالصور العامة منفذ سابقًا | تأكيد الفهرسة عبر Search Console، ومراجعة noindex للإدارة. |
| S03 — canonical | تنظيف معاملات الحملات منفذ سابقًا | مراجعة hreflang والروابط الفعلية باللغتين على الإنتاج. |
| S04 — sitemap | الخدمات وlastmod منفذان في المرحلة 5 | فحص الروابط المنشورة وSearch Console. |
| S05 — نشر المقالات | شرط النشر والتاريخ منفذ ومختبر | تأكيد نشر التعديل ومراجعة تواريخ المحتوى الحالية. |
| S06 — بيانات المقال والمحتوى المحلي | بيانات المقال المنظّمة منفذة سابقًا | بيانات الفروع والربط والمحتوى تحتاج حقائق تجارية وبيانات بحث. |
| Q01 — واجهة الهاتف | ترتيب البداية وتقليل الحركة منفذان محليًا | المعاينة البصرية على الهاتف والقائمة وإثبات الشواهد الاجتماعية؛ صور pravatar والعداد الموجود لم يُعتمدا كحقائق. |
| Q02 — الاختبارات وCI | 69 اختبارًا ناجحًا وإعداد CI أضيف | تشغيل CI الفعلي، وفحص MySQL والترحيل الخاص بتكرار الترجمات، وفحص الأجهزة؛ لا تُثبتها SQLite. |
| Q03 — الخادم والترويسات | لم تُغيّر إعدادات التشغيل | يلزم معرفة HTTPS وDocumentRoot وPHP-FPM والتضمين قبل فرض CSP/HSTS أو تخفيض الحدود. |
| Q04 — المراقبة والاستعادة | لم تُفحص أنظمة الإنتاج | تحتاج بيانات العمال والنسخ الاحتياطي وتجربة استعادة وCrashlytics والأجهزة. |
| Q05 — التحليلات والإيراد | لم تُغيّر أحداث التحليلات | يحتاج حسابات GA4/Firebase وتعريف الشراء المتفق عليه؛ ليس ضمن تعديل الدفع. |
